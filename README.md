# Planets-Explorer
A responsive planets explorer built with HTML, CSS and JavaScript. It loads planet data from a JSON file, lets you search for a planet, shows its stats in a card, and lists all planets in a grouped table. It supports light and dark mode.

## Live Demo
https://planets-explorer-six.vercel.app
